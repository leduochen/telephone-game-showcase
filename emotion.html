Data sources

Selected from a 30-pair experiment: three Mandarin pairs from DEBATE, one English instruction pair from IUDvPP, and one English statement–question pair from ContraProST. DEBATE and IUDvPP use human recordings; ContraProST uses the publisher’s synthesized speech.

What A and B represent

A and B share the same lexical script with different intended readings in the source metadata. These examples focus on meaning conveyed by pauses, attachment, and intonation. The English meaning labels describe those source readings; the original Chinese and English utterances remain unchanged.

Experiment setup

Each side starts an independent audio-only chain, repeated three times for each model. Every hop receives only the previous output audio in a fresh session. All four models use the same retelling prompt. Browse H0–H10 and compare A with B within each run.
